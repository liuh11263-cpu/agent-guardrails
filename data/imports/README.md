# 📥 冷启动经验导入目录 (Imports Guide)

在这个目录下，你可以把你在本地跟大模型（Claude, ChatGPT 等）对话时积累的**提示词、报错排查和执行工作流**，以最松散、最舒服的格式随手记录并丢进来，脚本会自动帮你做结构化合并。

---

## 支持的文件格式与规范

你可以直接创建以下三种文件丢进本目录：

### 1. Markdown 格式 (`.md`)
最推荐的记录方式。使用标准的标题划分区域，脚本会自动解析：

```markdown
# 你的工作流标题 (例如: 微信支付回调失败排查)

### 适用场景
当你发现支付成功但数据库未更新状态，大模型不知道怎么写验签或查单时。

### 执行步骤
1. 检查商户号证书配置。
2. 在支付回调接口中打印原始 Payload 日志。
3. 对齐微信官方验签算法，使用商户 key 进行 HMAC-SHA256 签名校验。

### 约束
- 不要把敏感密钥写死在代码里。
- 确保接口幂等，防止重复发货。

### 验证
- 模拟微信回调请求，接口返回 SUCCESS 并且数据库订单更新为已支付。
```
> **注意**：脚本会通过匹配包含 `场景`、`步骤`、`约束`、`验证` 的小标题，自动抽取列表。

---

### 2. 文本格式 (`.txt`)
如果你懒得写 Markdown 格式，可以直接写纯文本文件。多条经验之间用空行（或者 `---`）隔开：

```text
# 某某 API 请求超时排查
这个是适用场景：调用大模型 API 长时间没有响应。
- 检查本地网络代理配置，确认能 ping 通 api.openai.com
- 设置 requests/fetch 的 timeout 限制为 30 秒
- 增加 exponential backoff 的自动重试逻辑
```
> **注意**：纯文本中，第一行会被自动识别为标题，后续以 `-` 或 `*` 或数字开头的行会被自动识别为执行步骤。

---

### 3. JSON 格式 (`.json`)
如果你已经有了结构化数据，可以直接写 JSON 数组：

```json
[
  {
    "title": "Cursor 快捷键失灵解决",
    "summary": "重置快捷键冲突",
    "steps": [
      "打开快捷键设置",
      "搜索冲突的组合键",
      "解绑全局快捷键"
    ],
    "verification": [
      "组合键恢复正常功能"
    ]
  }
]
```

---

## 导入与更新命令

把文件丢进本目录后，在项目根目录下运行：

```bash
npm run skills:update
```

#### 该命令在后台会完成以下步骤：
1.  **解析与规范化**：读取本目录下的所有 md/txt/json，调用 `normalizeSkill` 将其转化为带有 System Role、约束和自动 `copy_content` 模版的标准 Schema。
2.  **质量打分**：对你的字段完整度进行打分（1-5分）。
3.  **合并去重**：与 GitHub 抓取到的数据、以及手工数据进行去重，高分候选写入 `data/processed/skill-candidates.json`。
4.  **人工审核（Approved）**：
    *   新导入的数据默认 `approved: false`。
    *   如果你希望直接在网站上展示，你可以把 `skill-candidates.json` 中你那条数据的 `"approved"` 改为 `true`，然后重新运行 `npm run skills:build`。
    *   或者，如果你是自己手动录入的经验，你可以直接写在 [data/raw/manual-skills.json](file:///Users/leo/2生成内容/8AI网站/data/raw/manual-skills.json) 中，并将 `"approved"` 设为 `true`，这样每次更新都会默认合并并直接在前台展示！
